# 1.0.11 可选月令分日表参考

出生资料新增“月令参考方法”。默认不定日限，不输出分日表候选；明确选择后，按《三命通会》四库卷二“论人元司事”首段转录表，展示出生区间涉及的表段、原文和来源定位。切换方法会使已有结果失效，需要重新生成或分析。

首段12个月、32个表段原词保留。艮土、坤土、巳土等只保留原文及明确的土元素，不擅自改成戊己。玉井异表和醉醒子反对固定日限的意见并列展示，仅供对读；电子资料未校勘影印原页，结果不被称为唯一司令或喜用神。

软件从十二节交接的实际瞬间起，每86400秒为一日，表段为左闭右开。短节月按下一节裁切，超过30日的尾段显示未覆盖；不按比例缩放或延续末段。时刻未知、重复小时或跨界时保留候选集合与不确定性。原扶抑和姓名排序保持原规则。

新版八字规则1.2、证据1.1保存方法、表、异说及原文定位；旧1.0/1.1使用冻结校验器，不补新表。固定来源、表、许可与生成时来源登记贯穿保存、历史、备份和PDF。

50个测试文件、404项测试及TypeScript通过；独立132边界和4月长例、方法/快照/来源/审阅回归通过。浏览器已检查默认、固定表、未知与旧版，以及1100大字/1280标准布局。当前Windows独立安装通过，45页PDF完整含原表与异说，无空白或孤立短页；7页证据已渲染目检。验收与最终产物记录见 `VERIFICATION.md` 和 `.local/month-111/`。完整调候、从格、合化、真太阳时及奇门姓名验局仍待后续实现；真实AI、原生关闭两种选择、代码签名和跨机验收保留原有边界。
