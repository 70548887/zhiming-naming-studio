# 官方历史姓名统计

文化知识库的“历史姓名统计”提供公安部《二〇二一年全国姓名报告》中的两张新生儿给名前十榜，共20条公布人数。资料固定在本地，查询不联网，不保存客户信息，也不影响命名推荐分数、已有方案或报告。

统计对象是2021年出生、截至2021年12月31日已完成户籍登记的新生儿。男性与女性榜分别统计；给名不含姓氏。这不是当前全国人口的同全名人数，也不覆盖这一出生年度在截止日之后才登记的婴儿。

输入明确的给名后分别显示两榜结果。男性榜“沐宸”公布22,958人，“沐辰”公布15,660人；两者独立查询，不按同音合并。“王沐宸”不会被自动去姓。未列入前十只说明该榜未公布人数，不代表0人、罕见或独一无二，也不推断另一性别的人数。

公布登记母数为总887.3万、男468.1万、女419.2万，精度为0.1万，未公布精确到人的分母及舍入规则。界面保留原始计数和名次，不折算成精确重名概率。报告公布的性别占比与用这些显示母数重新计算的末位存在差异，原文未解释，不能据此伪造精确分母。

来源为[湖南省公安厅转载的公安部报告](https://gat.hunan.gov.cn/gat/jwgk/jwzx/gabyw/202201/t20220126_22471460.html)。页面可见发布日为2022年1月24日；2025年的网页生成元数据不是统计更新。原表由两人分别读图、独立录入后逐项核对。本应用自行排版最小事实条目与来源信息，不发行原报告全文或原表图片。

固定数据标识为`mps-national-2021-registered-newborn-top10-per-sex`，项目数据版本为`mps-2021-registered-newborn-given-name-top10-per-sex/1.0.0`，它不是公安部官方修订号。知识包导入与回退不会替换此独立数据。更新年度时需新增有明确口径的版本，不能静默覆盖这张历史表。

真实全人口、包含姓氏的完整重名统计仍待取得覆盖明确、可持续更新的正式聚合数据或服务；这20条历史事实不代替该目标。
