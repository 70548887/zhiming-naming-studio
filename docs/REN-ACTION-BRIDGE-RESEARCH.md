## 三份合同为什么仍未直接成为规则

通关完整任注位于 `[47174,47600)`，先说“若杀重喜印”，再说“杀露印亦露”，称“显然通达”。电子本后接“煞藏印亦”，末语未校定，本轮不补字，也不把藏层对读单独采用成闭合规则。明藏位置是可直接记录的事实，“杀重”“喜印”则仍有独立语义前提。把它们替换成杀的数量、月支相等或先验成格标签，会重新引入未证明的旺度，甚至让结论反过来证明自己的前提。新相邻负例说明，只有字面杀印链并不足以闭合 `rescue-effective-reachable` 或 `resource-protection-resolved`。

同段“或官星化之，或比劫解之……”列的是同一财损印或其他障碍的替代救法。要证明本条具体救应，必须先明确此财确实损此印，再证明对应救法有力、可达，确实解除同一障碍。救法成员出现不等于救法成功；一个替代路径未证成立，也不等于已经穷尽其他救法。接口应支持不同规则的替代证明，不能将所有“或”放入一个要求全部成立的合取，也不能因未发现救法而直接判全盘无救。

金制木局完整任注位于 `[31372,31538)`，包括“会木局”“日主元神透出”、明庚辛“虚脱无气”、土休囚难以生金，以及无申酉丑而增寅辰时的木盛金衰。该段确有定性判断，但“虚脱无气”究竟在所声明范围内如何由底层事实充分成立，尚未形成无循环的采用合同；“金势愈衰”也不直接等于不能克任何一根木。此时建立组级命题比任意反写全部金木边更准确，但还不足以把 `clash-capability`、`wealth-effective-capability` 或救应可达统一赋值。

因此本轮最近可落地的成果是可独立约束下一求值器的原例和合同，未发现足以立即改变任意新盘有效作用的闭合通则。不存在为赶版本新增全为 unknown 的作用 profile。

## 下一阶段的具体依赖

1. 对每条攻击先保留精确源节点、目标节点或目标组、目标根载体、可达路径，再分别证明能力与净作用。不能把“此明金不足以制住指定木局”改写成所有金克木边失效。
2. 财坏印必须证明该财对该印有效；救应必须消费同一损坏命题，并独立证明救法可达与未受抑制。需要的不是另一个元素数量总分。
3. 有效根不能仅由同五行藏干存在、月令成员或已经证明的日干局部旺势推出。冲克能力、目标可受及抑冲助泄仍是独立条件。
4. 原句使用的旺、衰、休囚、喜印与会局，应按同一固定取法建立非循环判据及例外。充分路径失败只表示该路径未成立；没有必要条件或穷尽合同，不反推全局否定。

现有工程靶标仍是丙日寅根的 `clash-capability`／`clash-rescue-resolved`，辛财损乙印的 `wealth-effective-capability`／`resource-protection-resolved`，及同一阻断的 `specific-damage`／`rescue-effective-reachable`。本批新证据说明其中的距离、成员与藏根快捷替代为何不成立；它没有假称已为这些依赖提供真值。
