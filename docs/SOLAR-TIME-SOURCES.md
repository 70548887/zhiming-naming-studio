# 真太阳时：公式、时间口径与来源

1.0.20增加可选真太阳时。默认仍为出生地民用时间；已有客户与旧方案无需补填经度。切换时间基准只影响新分析、新方案，不覆盖原始生日、出生时刻、时区或公农历记录。

## 公式与输入

经度范围为−180°至+180°，东经为正、西经为负；±180°分别保留其所在的日期侧，不只对钟面取模。先用IANA时区把录入的民用日期时刻还原为实际UTC瞬间，再计算：

```text
地方平太阳钟面 = 实际UTC + 经度 × 4分钟
地方真太阳钟面 = 地方平太阳钟面 + 均时差（EOT）
经度修正       = 经度 × 4分钟 − 该实际瞬间的IANA UTC偏移
相对民用钟修正 = 经度修正 + 均时差
```

IANA实际UTC偏移包括当时的夏令时和历史秒偏移。UTC瞬间已经处理夏令时，计算真太阳钟面时不再额外减一小时。不存在的民用时刻仍拒绝；回拨重复时刻沿用第一次实际出现的时刻并提示，不声称已计算第二次。

这里只把时间转换为当地太阳钟面，不计算太阳高度、方位、日出或日落，因此不需要纬度。出生地文字不会自动转换成经度；经度须由录入者核对，不从地名猜测。

## 固定算法与精度口径

采用NOAA/GML公开网页JavaScript的Meeus儒略世纪均时差公式，以实际UTC时刻计算儒略日与儒略世纪；未采用只按日序计算的五项近似，也未采用NOAA电子表格中仅1901–2099有效的简化儒略日公式。

- 输入核验范围为出生地民用年份1900–2100。校正后钟面可能进入相邻1899或2101日期，保留实际跨日，不将其截回原生日。
- 内部保留浮点修正量和墙钟坐标。显示取其之前的整秒，不四舍五入越过时辰或日界；1970年前的负坐标同样向过去截断。
- 秒是显示分辨率，不是出生记录或观测精度。未加入UT1/UTC、ΔT、观测者地形或其他观测校正，不提供观测级误差保证。
- 距换日或整点不超过60秒时提示复核。60秒是产品提醒窗口，不是算法误差界或置信区间，也不会单因进入该窗口而暂停已知时刻排盘。
- 返回的太阳“epoch”是用于保留日期的墙钟坐标，不是另一个物理UTC瞬间，不可拿它替换原瞬间去比较节气。

NOAA已停止维护该计算器，并说明不保证其准确性或功能；本应用固定其公式以便复现，不声称NOAA认证或背书。天文钟面转换也不证明命名或术数判断有效。

## 八字、奇门与未知时刻

八字日柱按所选钟面00:00换日，时柱按同一钟面定时辰；奇门使用相同日时干支，由校正日干支回溯甲己符头。八字立春年界、节令月界、月令分段及奇门节气仍按原实际UTC瞬间判断。生肖及公农历生日显示保留原民用记录，不随太阳钟面跨日改写。

出生时刻未知时，保留该民用日期全部有效实际时段，在首末端点分别计算均时差，不把12:00代表值作为出生时刻。校正区间跨越真太阳日界时，不选定日柱、日主或喜用，不输出依赖日主的十神、调候及从格证据；仅显示实际区间内确定的年、月信息。无论是否跨日，未知时刻均不补时柱或唯一时家奇门盘。

新方案保存所选时间基准、原民用记录、实际UTC点或区间、经度、修正量、校正钟面及固定来源。恢复时以保存的出生资料与规则版本核验；旧八字1.0–1.7和奇门1.0–1.3按冻结实现保留，不回填新时间说明或来源。
