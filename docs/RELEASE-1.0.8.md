# 1.0.8 奇门盘层结构核查

本批继续实现既定传统扩展的第二阶段。保留甲己符头拆补、中五寄坤二、天禽随天芮以及既有时旬空、时驿马；新增结构包 `zhuanpan-structural-patterns/1.0.0`，基础盘版本升至 `1.2.0`。

## 实现范围

- 七条核查分别记录命中或未命中、盘层、宫位、主干/寄干、条件、来源提交和触发依据。
- 门迫只计门克宫；击刑采用天盘任一六仪宽式；入墓仅取乙坤二、丙乾六、丁艮八三奇表。丁乾及乙乾异表保留在来源说明，不混入本规则，也不称已覆盖十干入墓。
- 星、门分别逐项检查外八宫全部原位或全部对宫，称结构伏吟/反吟。它们是明确的软件分层定义，不是对古籍所有同名术语的统一裁决。
- 九宫显示命中标记，结构面板可展开未命中、条件与依据，PDF保留同一份快照。结果不参与名字评分、姓名落宫或人生吉凶断语。

## 历史与数据校验

既有1.0与1.1盘保留原内容，不补造结构快照。未知时刻不生成结构结论。当前1.2快照从保存的公/农历、时区及民用时刻重新核对节气与盘层，拒绝仅更换节气后生成的自洽假盘；同时校验完整规则、来源、核查状态、证据与九宫标记。

两个MIT来源、八份真实字节源码/许可快照及摘要锁可追溯。独立复验脚本运行锁定外部低层函数，并向其显式提供阴阳遁和局数，不调用其不同的定元逻辑或应用src。1,080盘是18阴阳局×60时干支的盘层算术对照，不能表述为1,080次独立出生时刻观测或古籍原页校勘。

- 全套256项测试、30个文件通过，含1,080盘完整层与结构结果对照、每规则至少3正3反、阴阳遁、寄中、寄干、多规则共宫和精确交节边界。
- 集成回归覆盖结构快照、审阅历史、备份往返、错误证据/规则/底盘/节气拒绝、旧版兼容与未知时刻。
- 独立复审复现并修复了自洽错误节气导入；重验确认正常盘、旧盘继续通过，错误盘与来源篡改被拒绝。
- 隔离浏览器实操确认7项核查、命中与未命中清单、展开来源和主寄干证据、真实1.1历史不补算、未知时刻无结构面板；1100像素紧凑大字模式无整页或展开面板横向溢出。

- 安装后的CJS、JS、CSS、HTML、结构来源锁和两份MIT许可与发布文件相同，开发用原始JS/Go研究文件未夹带进安装包。
