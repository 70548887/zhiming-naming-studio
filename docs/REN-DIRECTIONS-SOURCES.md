# 任注1.4：木方与火方的局部旺势

本来源包接续已发布任注1.3，但另立数据、来源锁和方法版本。它采用同一固定《滴天髓闡微》任氏评注中已经明确给出的局部充分命题：**寅卯辰或巳午未在已确定柱中齐全，日干已知且与该方同气，即可证明本条局部方旺。**

这是局部旺势，不是全局净强弱、每条根的有效性、相冲的实际胜负、从强格局或喜用神。本文记录来源与采用合同，不把尚未完成的产品运行、界面、PDF或安装验收预写为通过。

## 为什么这些条件足以得到局部正判

任注先定义“凡三字全为成方”，同段明列寅卯辰东方、巳午未南方。随后另一完整任注解释：“成方干透元神者，日主即方之气也。如木方日主是木，火方日主是火，即为元神透出也。”在此基础上明确说“成方透元神，旺可知矣”。这三项是同书原文直接给出的定义、同气身份和正面结论，不需要引入数值旺度、现代计分或最终格局作为种子。

“倘年月时干不杂财官，又有劫印，谓之从强”在后面另述从强及行运，其适用条件不能倒搬为前面局部旺势的必要条件。干支总论同样先说“大凡支全三物，其势旺盛”，再分旺神在提纲或别支、宜泄或可制。这说明局部势与实际制泄、取用是不同问题。

因此本条不因后续净作用模型尚未闭合而全部返回未知，也不因某个尚未证实的冲克、救应或财官分支而撤销已经成立的原句前提。它能给出正面局部能力，同时明确哪些进一步结论没有得到证明。

## 撤销没有原典依据的额外门槛

先前本地研究曾提出月份、第四支、明干和四柱全知的保守限制。正式审查发现这些限制会排除本书已经肯定方旺的原例，而局部充分句没有要求它们。本版全部撤销，不因窄域更易测试便将其称为原典必要条件。

| 不再作为门槛的因素 | 原典证据与处理 |
| --- | --- |
| 必须寅卯月或必须午月 | 原文先给成方同气日干的正面命题，再谈当令/他支如何制泄。原例包含辰月木方、未月火方；月份仍保存，但不一票否定局部方旺。 |
| 第四支必须亥、卯或重复午 | 原定义是三字全，不是某个精确四支白名单。混局与同支重复保留，不擅自删除成员。 |
| 明干只能木水或木火 | 有丁火吐秀、戊土财、癸丙及庚辛等原例仍有局部势。金、财、泄秀影响具体作用，不等于方旺不存在。 |
| 四柱必须全部已知 | 若已知三柱已经给出全部三支，且日干同气已定，充分事实已经成立。未知第四柱不补造，也不吞掉已知正面证据。 |

这些因素从证明门槛移到背景事实或待核影响，不表示它们没有作用。完整性保留为元数据，`requiredForProof=false`；相冲、明藏干、根联系、合会、重复支和输入不确定性继续保存。

## 证明与未知输入的处理

每条合同只有两个进入证明依赖的来源谓词：方向三支在已知柱齐全，以及日干已知同气。木方日干为甲乙，火方日干为丙丁。火方是任氏明确例示，不是把木局能力按五行矩阵自行推广。

| 已知事实 | 本条路径 | 局部能力 |
| --- | --- | --- |
| 已知柱已见齐三字，已知日干同气 | 条件齐备 | 已获原句支持；可以缺时柱 |
| 三字未齐，四柱已确定 | 本条条件不符 | 仍不能反推全盘不旺或能力不存在 |
| 三字未齐，尚有缺柱，且没有其他已知不符前提 | 成员谓词待核，整条路径继续待核 | 不把未见当作没有 |
| 日干尚未确定 | 待核 | 不补造日主 |
| 日干已知异气 | 本句日主同方条件不符 | 不否定其他原句可能描述的该方之势 |

成员谓词与整条充分路径分别记录：例如缺时的木日盘，火方成员谓词可以未知，但已知木日已经不符合本句火日条件，因此火方整条路径为`not-met`，局部能力仍为`unknown`。任一已知不符前提足以排除本句路径，不会被另一个未知谓词改回未知；排除本句仍不是对该方不旺的反证。

例如2023-02-15北京民用日，年、月、日可确定为癸卯、甲寅、甲辰，即使时刻未知，寅卯辰与甲日已经齐备。该盘可得到木方局部正判；未知时柱及全局净作用仍如实保留，不用中午填入一个假时柱。

## 相冲是否破坏了充分命题

固定原文的一般相冲段说“得令者冲衰则拔，失时者冲旺无伤”，又要求“必先察其衰旺，四柱有无解救”。它否定了“只要相冲存在就必然去神”的快捷规则；实际冲能否破坏根、方或秀气还需要作用力、位置与解救。反过来先要求完整冲胜负，才允许局部旺势成立，会把本应作为输入的旺势与冲效果相互证明，造成循环。

同书丙辰／庚寅／乙卯／丁亥原例有后行酉运“冲破东方秀气”的描述。该段说明实际后运破坏可能发生；它没有公布“原局任一第四支为酉便必破方”的一般充分算法。本条只处理保存的出生原局，不把该次后运结果注入任意新盘，也不宣称后续金运无害。

所以本版保留结构相冲及所有原节点，并将其实际净作用留待后续独立证明；既不自动删去方向支，也不把“局部方旺”说成“永不受克”。将来如采用同体系明确的有效破方规则，应另给原句、靶标、完整条件与独立正反例，再版本化接入；不能静默改写旧方案。
