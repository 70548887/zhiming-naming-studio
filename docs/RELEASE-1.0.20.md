# 1.0.20 可选真太阳时（本地验证版）

本版为出生资料新增“民用时间／真太阳时”选择，默认保留民用时间。真太阳时需录入出生地经度，东正西负，按实际UTC瞬间计算经度修正与NOAA/Meeus儒略世纪均时差。出生地文字不自动猜经度；此功能不计算太阳高度角，故不需纬度。

原始生日、时刻、IANA时区、公农历及生肖显示保持；八字和奇门日时干支使用所选钟面，仍采用00:00换日。立春年界、节令月界、月令分段和奇门节气按原实际UTC瞬间判断。IANA偏移包含夏令时，不额外重复减一小时。时刻未知时保留全部有效区间并分别校正端点，跨真太阳日界不补日柱、日主、喜用或依赖日主的证据，也不产生时柱及唯一奇门盘。

新方案保留时间基准与修正过程，旧方案按原八字／奇门版本冻结，不回填新来源。选用真太阳时可能改变日时干支及其后续名字建议，应生成新方案保存该选择。完整流派判断、姓名落宫验局及真从合化并未由这项时间换算补齐。

固定来源为NOAA公开JavaScript，原件摘要、原句、署名和独立例证随包保存。NOAA已停止维护原计算器；本应用采用可复现数值模型，秒为向过去截断的显示分辨率，不代表观测或出生记录精度。60秒近界窗口仅提示复核，不作为误差界，也不因该提醒自动停盘。范围、公式及许可见[SOLAR-TIME-SOURCES.md](SOLAR-TIME-SOURCES.md)。
