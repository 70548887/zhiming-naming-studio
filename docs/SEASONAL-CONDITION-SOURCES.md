## 本轮7条规则

| 日干／月支 | 可核部分 | 保留未核的部分 |
| --- | --- | --- |
| 乙酉：白露至秋分 | 当前出生可能瞬间是否在该真实节气区间 | 桂蕊未开及据此取用癸水的整体解释 |
| 乙酉：秋分至寒露 | 是否已过秋分且仍在酉节月 | 桂花已开、喜向阳及丙癸取舍 |
| 癸辰：清明至谷雨 | 是否在清明至谷雨间 | 火气未炽与丙火整体适用性 |
| 癸辰：谷雨至立夏 | 是否已过谷雨且仍在辰节月 | 辛甲辅助等传统意见是否适合全局 |
| 乙寅“丙癸两透” | 非日柱明干中丙、癸是否均出现 | 原句后续科甲断语不采纳 |
| 庚辰“甲透丁藏” | 明干见甲、所选藏干表见丁 | 原句后续取用、命运断语不采纳 |
| 辛丑“壬丙俱藏” | 藏干表中壬、丙是否均出现 | 不据此判断强度、司权或原句后果 |

前四项均为**部分时间前提**：即使时间结果满足，原分支也没有因此整体满足，旧未实现结果不升级。寒露和立夏上界来自相应节月的软件范围，原文并未在这两处另外明示该上界。新增记录的 `proposedUses` 始终为空，不改变初始用字、喜用神或排序。

后三项属于新补录的明示透藏事实，与旧15条条件独立，不能计成“已解决原条件的三项”。“藏”按当前已固定的藏干表检查，不代表当令；“两透”只作位置有无的事实，缺柱时未见保留未知。

## 时间与未知口径

使用既有固定历算接口给出的真实节气瞬间，采用左闭右开 `[from,to)` 软件约定；不按午夜或日期整数判断节气前后。已知时间按出生民用钟映射的实际瞬间核对；未知时间对当日全部有效瞬间范围核对，跨界保留不确定，不选中午代替。

这不包含“上半月／下半月”等于15个24小时的假定，也没有自设多、旺、弱、成局、从化阈值。乙午／癸未的半月取法、丙亥旺弱、丁午成局等继续保留未实现。
