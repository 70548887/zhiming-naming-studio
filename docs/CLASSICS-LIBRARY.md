# 离线原典全文库

文化知识库中的“原典全文”收录两部固定电子版本，可按原文关键词检索、筛选书目、翻页浏览目录并连续阅读章节。检索结果保留原书位置；打开结果后高亮对应原字。空检索显示全部目录，有关键词时统计实际匹配位置，同一节可以有多处命中。繁简异写和近义词不会自动替换；检索词超过200个Unicode字符时明确报错，不截断后继续查找。

123个分节无重叠地覆盖全部180447个原始码点，卷首与末尾页面信息没有丢弃。原始文本共501799字节；计数包含电子转录格式标记，不等同于正文汉字数。原字、疑字、标点及原表列序均保留。穷通电子本的9处私用字不猜换为其他汉字，相关章节会提示核查。电子转录尚未完成独立逐字影印校勘。

“阅读”模式仅整理已识别的电子格式，保留原注、任氏评注及原表正文；未知或不完整结构继续可见。每一段可读文本均保存到原始码点的对应关系，高亮沿该关系定位。“原始文本”模式提供完整未改写的章节内容。匹配只落在被隐藏格式中时，提示切换原始文本核对，不制造一个正文命中。来源面板提供固定修订、许可、章节范围和摘要。

两书是独立的只读资料，不由自定义知识包覆盖，也不加入既有名字方案的来源快照。全文阅读不自动扩充命名出处规则，不把尚未实现的有效生扶、制化或姓名验局当作通过。既有八字、奇门和姓名评分仍使用各自已登记的方法与规则。

电子转录、分节索引和依其整理的说明按CC BY-SA 4.0保留中文维基文库贡献者署名、固定来源、修改说明和相同方式共享。每书NOTICE随原件发布，完整许可见`data/raw/CC-BY-SA-4.0.txt`。原书与电子转录、项目整理和应用代码的许可分别记录。

数据位于`data/classics-catalog.json`、`data/classics-source-lock.json`、`data/classics/`及`data/raw/classics-*`。加载时核对目录、原件、分节、来源与许可。`npm run data:classics`可离线重建并逐字节验证6个派生文件；该验证命令不下载、不修改现有文件。需要重新生成时，可在源码项目运行`node scripts/build-classics-data.mjs`，其输入仍是固定摘要的原始电子文本。
