# 转盘结构辅助规则：固定取法与独立证据

规则包版本：`zhuanpan-structural-patterns/1.0.0`。适用基础盘保持“时家转盘、甲己符头拆补、中五寄坤二、天禽及中宫干随天芮”。不引入飞盘、置闰、茅山或另一种三元定法。

本模块只标记盘面结构，不输出命运、灾祸、健康或性格断语，不加入名字总分，不建立姓名落宫。时刻未知时不生成唯一盘面，也不为旧方案补造原先不存在的计算快照。

## 1. 启用的七条规则

每条规则单独保存规则 ID、版本、来源定位、适用条件及实际触发依据。没有命中同样是已完成检查，不等于漏算。

| 规则 ID | 固定取法 |
|---|---|
| `qimen-door-menpo/1.0.0` | 门迫，**门克宫**；宫克门不标门迫。|
| `qimen-heaven-yi-jixing/1.0.0` | 六仪击刑，**天盘任一六仪的宽式**。|
| `qimen-heaven-qi-rumu/1.0.0` | **三奇**入墓，乙坤二、丙乾六、丁艮八。|
| `qimen-stars-fuyin/1.0.0` | 外八宫八颗主星全部处于各自本位，称星盘原位（结构伏吟）。|
| `qimen-stars-fanyin/1.0.0` | 外八宫八颗主星全部处于各自对宫，称星盘对宫（结构反吟）。|
| `qimen-doors-fuyin/1.0.0` | 八门全部处于各自本位，称门盘原位（结构伏吟）。|
| `qimen-doors-fanyin/1.0.0` | 八门全部处于各自对宫，称门盘对宫（结构反吟）。|

星盘和门盘分别检查，不能由星伏推断门伏、由星反推断门反。对宫是坎一↔离九、坤二↔艮八、震三↔兑七、巽四↔乾六，即外宫号 `n ↔ 10−n`。九宫展示中的天禽寄宫说明不算一颗独立转动主星；天禽跟随天芮，不以中五“没到对宫”否定外八宫的结构反吟。

“整层原位/对宫”是本软件明确采用的可复算结构定义，依据固定本位表与外八宫刚性转动。特别是门层，不声称本轮取得古籍逐条定义的独立原页；也不把上游逐宫十干克应里另称“伏吟”的同干组合混作整盘结论。

### 门迫表

| 门 | 命中宫 |
|---|---|
| 开、惊（金） | 震三、巽四（木） |
| 休（水） | 离九（火） |
| 生、死（土） | 坎一（水） |
| 伤、杜（木） | 坤二、艮八（土） |
| 景（火） | 乾六、兑七（金） |

共有 13 对。只有门克宫方向命中；例如开门临离九是宫克门，不标门迫。生门在艮八等同属性组合也不命中。

### 六仪击刑表与范围

| 天盘六仪 | 所隐六甲 | 刑支 | 命中宫 |
|---|---|---|---|
| 戊 | 甲子 | 卯 | 震三 |
| 己 | 甲戌 | 未 | 坤二 |
| 庚 | 甲申 | 寅 | 艮八 |
| 辛 | 甲午 | 午 | 离九 |
| 壬 | 甲辰 | 辰 | 巽四 |
| 癸 | 甲寅 | 巳 | 巽四 |

固定采用上游明示的“宽式（任一天盘六仪）”。只看本旬值符所带仪的“严式”属于另一种判定范围，本版本不同时启用。Go 来源支持相同六刑宫表，但不构成它也采用宽式范围的证明。

只检查天盘主干及随天芮实际寄落的中宫干，不检查地盘。寄干明确标注“寄干”，按实际落宫查表；中五的说明格不再计一次。由此可以在一个宫里有多个不同触发条件，不能互相覆盖。

### 三奇入墓的固定分歧

本规则只覆盖乙、丙、丁三奇，**没有完成十干入墓**。选定资料口径为《奇门遁甲统宗》《奇门旨归》上游转录中的乙坤二、丙乾六、丁艮八。主干和寄干按天盘实际有效落宫检查，地盘不计。

明确保留但不混用的分歧：

- Arc 同时转录《奇门宝鉴御定》丁墓乾六的另一读法；本版本不启用丁乾六。
- Go `QMTomb` 把乙记为戌，按固定地支宫即乾六，和本版乙坤二不同。该表不是本版三奇入墓表的“一致交叉来源”。
- 丁在乾六只作为所保留的另一派资料，不生成本版三奇入墓命中；乙在乾六也不会因 Go 异表而自动命中。

## 3. 独立盘例与复验

`tests/fixtures/qimen-patterns-examples.json` 包含 **1,080 张完整盘层期望**：阳、阴各九局，每局 60 个时干支。基础层由锁定外部原文件的低层函数直接运行；夹具生成与复验均不导入应用 `src`。每例保存显式局数及对应节气/符头输入，原位、对宫、三种逐宫标记分别保存预期。

复验使用 Node `vm.SourceTextModule` 执行原归档模块。上游静态导入的 `Solar` 以任何调用都会抛错的依赖替身链接；低层盘函数不调用它，因而不安装或借用应用的历法库，也不运行上游另一种定元。寄干在上游九宫数组中保持中心，本证据明确把它寄至上游算出的天芮实际位置，再用独立转录并双源核对的表查验一次。

| 检查 | 命中盘 | 未命中盘 |
|---|---:|---:|
| 门迫 | 720 | 360 |
| 六仪击刑（宽式，含寄干） | 572 | 508 |
| 三奇入墓（乙坤丙乾丁艮，含寄干） | 370 | 710 |
| 星盘原位 | 240 | 840 |
| 星盘对宫 | 120 | 960 |
| 门盘原位 | 240 | 840 |
| 门盘对宫 | 120 | 960 |

每项在阳、阴遁各有命中与不命中，数量均超过至少 3 正 3 反的阶段要求。另标记旬首仪居中、时干居中、值使经过中五、寄干击刑、寄干入墓、多规则共宫。夹具中的门迫未命中是整盘无门迫，共有 360 盘，不仅是局部非命中宫。

只读验证命令：

```powershell
node scripts/verify-qimen-pattern-evidence.mjs
```

`--write` 只供审核固定来源后重建开发夹具，不是发布验证命令。脚本校验八个源文件的完整摘要、MIT 声明、六刑双源一致、门迫 13 对锚点、三奇分歧、全部盘例和各规则正反覆盖；主应用测试再把实际算法与这些外部期望逐盘比较。源复验通过不单独代表界面、备份或 PDF 已验收，那些由发布验证另行记录。
