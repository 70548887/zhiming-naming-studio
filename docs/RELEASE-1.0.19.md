# 1.0.19 命名出处扩容与字义映射修复（本地验证版）

本版将经过语境审阅的命名出处由14条扩展为40条，共44个双字名字：34个原文连续出现、10个选字重组。新增26条、27名，覆盖令仪、攸宁、明哲、纯熙、丽泽、行健、琼瑶等；重组说明、婚恋和祭礼等原语境保留。维翰、宜君、秉文三条候选未纳入，详见[命名出处审阅](NAMING-CITATION-REVIEW.md)。

新生成的引用必须同时匹配固定`id`、`sourceId`、`title`、`chapter`、完整`text`，并核对指定摘录、姓名与默认拼音；同ID但换来源、标题、章节或全文的条目不再冒用已审出处。有精确出处及组合说明时，寓意使用该句原义与现代家庭期许，不把攸=所、景=大、纯=充盛、丽=附丽等用法套回全局泛义。字典原文继续独立可查。

字库由774增至779字，补入厚、自、强、升、慎，使厚德、自强、允升、淑慎四个既有名字可生成；“松”明确选用MOE松科植物词条，修复先前误选“鬆”的松弛义。原始来源缓存未改写。厚、自、升暂缺康熙来源，相关五格暂停，不以普通笔画补算。
