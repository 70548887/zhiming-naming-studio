# 命名释义7.0：保存逐字审阅，独立核对整名出处

本页说明1.0.35的功能与适用范围；具体测试、安装与签名状态以同版本安装包旁的发行记录为准。

原知识包仍为779字，字典原义、读音、原有五行意象标签和知识包身份不改。本版补充此前562字的命名适用义审阅：304字可展示已审通用说明；161字有语境限定，需要起名师结合完整名字人工核对；82字待审；15字暂不推荐按当前读音与用途自动取意。人工待确认并不会自动变成已批准，也不据此生成逐字家庭期许。

逐字卡保留词典原义、所选词条、读音、采用条件与项目说明。家庭期许属于项目创作；通用单字取意不代表某个完整名字在古籍中的采用义。内部审阅标记以中文提示展示，原保存记录不改。例如，单字莹有透明光洁义，但整名琼莹所取诗句中的莹采用美石义；两者分栏说明。

本版增加20个完整姓名出处记录，14个为连续取字、6个为同句重组。完整姓名、顺序、读音、原词条、原句和义项都匹配才采用。琼莹已按同句美石义修正；琼英保留复词来源作待审材料，未授予新增组合出处信用。新增整名出处沿用既有出处评价方式；304条新增逐字说明只用于展示，不额外增加语义、主题、行业或辨识评分。

仅对实际内置知识包匹配的新版方案启用本规则。主进程核对实际SQLite完整摘要和对应版本，客户端不能自报可信上下文。合法自定义知识包继续按其适用的旧规则处理；已有4.0、5.0、6.0和无独立版本的历史方案保留原解释、评分与来源，不以当前资料回填。

每份新方案保存逐字审阅快照。详情、比较、审阅历史和PDF读取该份记录；起名师可修改原有寓意、理由与备注，不能通过普通审阅接口伪造逐字审定状态。保存、重开、历史、备份及恢复均核对固定来源和快照一致性。

来源出版表、原件与勘误记录见data目录的naming-editorial-v7相关文件。固定词典原文与项目自编说明分别保留其许可与归属。维护时可运行：

~~~powershell
node scripts/build-naming-editorial-v7.mjs --verify
node scripts/verify.mjs --profile source --output verification-output/source-check-001
~~~

离线重建从18个固定资料输入生成出版表、说明与来源锁，再逐字节核对既有产品。它不依赖开发者历史工作目录，不默认改写数据，也不访问网络。

本版没有补成完整八字用神、传统奇门姓名验局或唯一的汉字五行归属。音韵扩展与元素人工确认仍在下一批独立开发中。
