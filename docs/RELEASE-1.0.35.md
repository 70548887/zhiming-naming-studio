# 1.0.35 功能与适用范围

本文件说明版本功能。发行时随安装包提供的 NamingStudio-1.0.35-verification.json 记录实际测试、构建、安装、PDF检查和未完成事项；本文件不预先承诺验收结果。

本版补充命名释义与整名出处，新增不可编辑的逐字审阅记录，并接入详情、比较、历史与PDF。通用单字取意、完整名字的原句选义和项目家庭期许分别说明，人工待核内容保持待核。范围与数据覆盖见[命名释义7.0](NAMING-MEANING-V7.md)。

修正通用取意说明拼接的重复句号，将内部审阅标记改为准确中文，并区分没有新候选与收藏列表为空的提示。父母姓名、原有避讳、姓名评分及旧方案的保存机制继续保留各自规则边界。

维护工具提供统一来源验证、离线重建和固定版本的Windows CI配置。源码中的README与CURRENT-STATUS是外部发布状态文档，不属于安装载荷；安装包保留功能、使用及许可说明，避免内置动态状态文档过期。

本版没有完成完整传统用神或奇门验名核心。音韵扩展、元素人工确认、真实外部AI、原生文件选择器、发布签名与跨机验收分别按其实际发行记录判断，不能从单个组件通过推定整体完成。已通过的1.0.33原生关闭两按钮记录保留。
