# 1.0.7 方案目录与交付体验

本批实现原 UI 计划中的方案筛选排序、导出确认、快捷键及本机显示偏好。1.0.6 的五项审计修复和生成提交保护继续保留。

## 方案目录与展示

- 方案可按客户、姓氏、关键词、创建日期和收藏情况组合筛选，显示匹配数/总数并支持清空条件。日期按北京时间，包含起止当天；无效或倒置日期明确提示，暂停结果而不是显示“无匹配”。
- 每批显示稳定的批次编号、完整创建时间、候选数和收藏数。排序和筛选不会重写保存记录。PDF、导出确认与建议文件名使用同一批次编号。
- 工作台按生成顺序、音韵、语义、读写或辨识度展示；同分保留原序，原候选编号和ID保持不变。评分、收藏与PDF名单顺序不受页面排序影响。

## 导出确认

- 导出前核对客户、出生记录、批次、实际名字名单、总意见和已保存品牌。
- 有收藏时只导出收藏，无收藏时导出全批；数理待确认会说明数量，可导出当前真实状态。
- 有未保存意见时，确认后先保存意见。未保存品牌不会混入PDF，确认页明确提醒返回设置保存后再使用新品牌。
- 返回审阅不保存、不导出。文件窗口取消时提示意见已保存；导出失败保留确认供重试，同步忙锁避免重复提交。

## 快捷键与显示偏好

- Ctrl/⌘+S 保存当前可保存页面；Ctrl/⌘+K 聚焦当前搜索；Ctrl/⌘+Shift+E 打开导出确认。无对应操作时不拦截按键。帮助只列当前可用动作。
- 输入法组字、重复按键和已有弹窗会暂停全局快捷键；“?”仅在非输入位置打开帮助。弹窗仍使用操作按钮与Esc。
- 舒适/紧凑只调整间距；标准/大字输入为13/15px。设置立即生效，只在本机存储密度和字号，重新打开保留；损坏或保存失败会提示并回退，不写客户库。

## 本批验证

- 全套233项测试、27个文件通过，包含目录日期边界与稳定排序、候选展示不改原数据、确认名单与PDF取法一致、显示存储和快捷键条件。
- 当前 App 源码处理器还验证了确认前不写入、重复确认只提交一次、总意见先保存、文件取消、失败保留重试；该测试不是系统文件窗口端到端测试。
- 隔离浏览器实操：3批跨北京时间午夜的样例筛选、倒置日期即时提示、稳定批次与时间排序、Ctrl+K、Ctrl+S、确认收藏名单和待保存意见、浏览器文件操作不支持时保留错误、紧凑大字重载保留。
- 窗口检查：1100大字紧凑、1280及1460布局，无整页横向溢出；候选保持两列/三列，确认窗口可滚动。
- 生产安装在独立 `-Case ui-107` 目录通过，移除开发工具PATH后退出码0；实际桌面目录和导出确认可用，确认的12个名字逐项与保存方案相同，批次编号与PDF封面一致。系统加密密钥、五格确认及奇门辅助面板继续通过。
- PDF共29页，无空白或孤立短页，全部候选姓名在PDF中，发布主程序、预加载、JS、CSS、HTML与安装内容一致。
