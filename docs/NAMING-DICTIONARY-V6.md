# 命名字典6.0：原词条与审阅用途分开

1.0.33源码采用 `naming-editorial-6.0.0`，独立来源为 `naming-editorial-dictionary-v6-fixed`；新内置知识包为 `2026.10.20.2`。本版开发验证已完成：186文件／2294项完整回归、生产构建、隔离桌面／浏览器及声明范围的PDF检查通过；最终安装与交付结果以[验证记录](VERIFICATION.md)及包旁实测记录为准，不提前宣告安装通过。

## 九字的默认选词

固定原辞典中的不同本字可能同音，不能因此合并义项。本批仅纠正下列默认选词，默认拼音和声调均保持原值，不批量改动其他简繁或异体关系。

新包共779字、143个多音字；九字以外770字完整记录不变。各本字的全部异读和原义项分别保存，原1833引文、433固定知识及原67条／71名出处规则不增加。普通笔画、异体集合、既定字形五行、康熙候选及传统取法不因本次选词纠正重算。

沈的shěn原条只有姓义；chén原释义字段为空，原链接文字为“同「沉」。”。新资料保留空释义和链接原结构，把该异读显示为“辞典参照：同「沉」。”，并以 `referenceOnly` 和配对来源字段标示，不展开成沉稳，也不借给shěn。旋的xuàn保留打转、温酒、临时／现时等原义；xuán的回／归另存，不混到默认音。

咸原词条第四义中的“艮（☱）下兌（☶）上”存在字名与符号冲突。原文逐字保留，以 `pendingQualityIssues` 及独立待核说明登记，不自行校字，也不拿这一条自动推卦。选对原词条不表示全部字典义、项目意象或命名用途均已审定。

## 仅三项项目用途迁移

- 冬：“坚韧（项目原创季节类比，非字典原义）”，以冬季意象表达家庭期许。
- 秋：“收获（项目原创季节类比，非字典原义）”，以秋季与秋收的联系表达期许。
- 致远：仅审致zhì“達到。”与遠yuǎn“時間、空間的距離大。與「近」相對。”所构成的现代自然搭配，不增加经典引文或对致字其他用途的批准。

这些用途同时绑定字、拼音、声调、来源、原词条和采用义项。项目概念与可见说明分开保存，避免把说明文字本身当作新的语义信用。九字纠正不自动迁移其他项目寓意、风格标签或行业意象；沈旧有“明朗”默认编辑标签因shěn姓义没有依据而移除。其余13条字典审阅线索本批未采用。

## 新旧包与保存方案

在知识库维护页可分别查看当前活动包和本版内置包。点击“预览本版内置字库”后，先核对完整哈希、来源及增删改，再“确认使用本版内置字库”。这会切换整个知识包，自定义条目是否移除须查看差异；取消不应用，回退也先预览确认，只切换知识资料，不撤销客户方案与审阅。

新规则不会替旧活动包补造新原义。新6方案若仍用旧包的鼕词条，就按保存的鼕及鼓声原义核验，不能获得仅针对冬词条的季节类比迁移。规则版本与字库版本分别保存；已有3.0／4.0／5.0方案继续使用各自的解释、评分、来源与归档，不自动升为6.0，也不猜填真正无版本的旧记录。

新6方案的PDF新增“生成时字库原义与读音”，单列保存的词条、选音和原义；其他读音及辞典参照不并入当前解释。旧5报告不加入新字典卡。实际开发版旧5冬方案与已交付1.0.32原报告函数的完整HTML为116914字节，逐字节相等；三份新／旧开发PDF共84页完成限定内容与全页检查，3个代表页直接目检通过。后续1.0.33最终安装版已完成独立验收，27份当前方案、7条历史、4归档及3份84页PDF的实际范围见release/NamingStudio-1.0.33-verification.json；本段前述开发验证与最终安装验证分别保留。
