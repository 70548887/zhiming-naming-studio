## 本次采用的充分子域

应用只有在以下条件全部成立时，才采用上述两条正面证明：

1. 年、月、日、时四柱完整且已知。
2. 月支是卯，日干是甲或乙。
3. 四支恰为亥、卯、未、辰，各一支，取原文木局加辰余气的分支。
4. 四个明干仅为甲、乙、壬、癸。

卯月及明干仅木水是**项目采用的保守限制**。原文旺极句没有独立规定必须卯月，也未把所有其他明干一概排除。产品没有把这个有限子域写成任氏全部推演方法，更没有把域外判为“木不旺”或“辰不能生助”。充分证明路径未匹配，只表示本条没有给出结论。

全部所选藏干继续保留。未中丁、己及辰中戊、乙、癸不能为了得到“纯木水”而被删除。原文的“四柱纯木”“全无克泄”等语义也不能机械改为所有明藏成员的零计数。

本条不纳入大运流年。未来扩大到其他月、其他第四支、明干火金土或岁运，必须增加对应来源合同和反例验证，不能静默扩大这条充分条件。
