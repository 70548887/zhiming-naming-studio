## 五场景合同

| 场景 | 原句条件 | 可核和未核边界 |
| --- | --- | --- |
| 丙亥 | “壬多无甲……或壬多有甲无戊，却非从杀” | 壬多未定阈值，甲戊的明暗范围未明；正反两条原句均保留依赖，不能单见甲或未见戊就否定 |
| 丙子 | “四柱多壬无甲……水多、有甲、无戊，却非从杀” | 正句多壬与反句水多不偷换；多寡及甲戊作用域仍未核 |
| 丁子 | “仲冬水多癸旺，全无比印……见丁比出干，难合格局……戊出破癸” | 可见额外丁明干、戊明干；水多癸旺和完整无比印未核，戊出现不等于确能破癸 |
| 庚午 | “一派木火，无伤、印、比劫，又作从杀而论” | 可核无戊己明干和无额外庚辛明干的子集；一派、伤含义及明暗有效生扶范围未核，子集满足不是完整无印比 |
| 癸午 | “一派己土，无甲出制，此作从杀而论” | 甲明干有无可观察；一派己土和有效出制未核，甲存在不单独证明反向条件完整成立 |

没有给“多”“旺”“一派”设数量、占比、扶抑分或力量阈值，也没有把“无伤”擅解成某一确定食伤集合。日主自身不计作额外出干；藏干不等同出干，缺柱未见不能证明不存在。

## 反向原句的依赖

每条反向分支明确列出前提条件编号和信号编号。依赖编号不存在会被资料加载器拒绝，不能默默略过。

- 只有全部前提和信号均明确满足，才能给出“本条路径反证”；这仍不是全部从杀流派的否定。
- 某个位置事实已见，但水多、癸旺或制化前提尚未实现时，分支继续待审，仅显示已见信号与缺失前提。
- 某一信号明确未见，可显示本反向分支未触发；这不等于正向从杀已成立。
- 缺时或交节待定时，已知存在仍可确定，未见则按相应范围保留未知。

六个可执行谓词只属于 `support-only` 或 `rejection-signal`，不把未实现必要降为支持。必要条件仍列于结果，所有本轮真实路径整体保持待审。原文科甲、富贵、家属、性格、疾病或命运断语不作为软件结论。
