# 命名出处选义审阅与匹配

1.0.19 将命名出处规则由14条扩展为40条，覆盖44个双字名字。其中34个在所选摘录中连续出现，10个由原句选字重组；重组名字明确说明“并非原文连词”。本轮新增26条规则、27个名字，原有14条的名字、摘录、读音和语境说明保留。

这些规则是项目编写并经全文语境复核的命名选义，不是字典原文、姓名学专家认证或命运判断。检索库中的1,833条引文仍可供阅读，未审定的字面共现不会自动成为名字出处。

## 审阅方法与原文

新增规则覆盖15篇《诗经》和7个《周易》卦的原文。先通读对应诗篇，或卦辞、六爻、用辞与大象，再记录叙事情境、实际词义、默认读音、摘录位置和现代命名引申。独立复审与程序匹配分开进行；不能拿应用生成的解释反过来证明古义。

- 《诗经》原文使用 `chinese-poetry/chinese-poetry` 固定提交 `b8594f81a89752241442f2ce267d6f66f96704ee`。
- 《周易》卦爻与大象使用 `koriyoshi2041/zhouyi` 固定提交 `c74ae5a89e4b01da03fc8024d653f764ffd10aef`，不包含完整《十翼》。
- 字典读音和原义使用固定MOE缓存 `a6dc997417507eb510fc29822bc514de2c92728c`，原文不改写。另核“昭明、麗澤、德音、景福、和鳴”等复合词。
- “纯熙”的补充语义核对见[《毛诗正义》卷十九《酌》](https://zh.wikisource.org/zh-hant/毛詩正義/卷十九)：纯为大、熙为兴，疏释大明盛，不能替换为纯洁。
- “鸣谦”核对[《周易正义》谦六二固定版本](https://zh.wikisource.org/w/index.php?title=周易正義/02謙&oldid=2000726)，按谦德声名为人所知取意；不混用上六行师语境。

## 软件匹配与解释

每条规则保存固定引文五字段：`id`、`sourceId`、`title`、`chapter`、完整`text`。构建时对固定原文精确核对；新生成时传入引文也必须逐字段相等，且名字、指定摘录、逐字默认拼音均匹配。只有ID相同、只保留片段或改变书名、章节、来源、全文的自定义引文，不取得本条已审出处或绑定的原义解释。

有有效固定出处及经审组合说明时，候选寓意使用“原文选义与组合寓意（项目原创解释）”，不再拼接全局逐字意象。例如攸宁不拼成水流悠然，景福不拼成风景，纯熙不拼成纯洁，丽泽不拼成美丽恩惠。字典原义仍可在详情查看。缺少这组精确匹配时，不继续发布其出处绑定的组合解释；现代自编组合与待审义项按原规则处理。

本轮修复“松”误选“鬆”的字典映射：在Unicode允许的字形候选中明确选择MOE“松”词条的松科植物原义，不改写原字典。补入厚、自、强、升、慎五字，使旧规则厚德、自强、允升、淑慎可实际生成。强取qiáng与“加強。”，不混用qiǎng、jiàng。普通笔画与康熙笔画继续分别处理；厚、自、升暂缺康熙来源，涉及这些字时暂停五格。
