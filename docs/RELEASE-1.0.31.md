# 1.0.31 · 命名释义读音绑定

修复合法导入字库切换读音后，仍借用默认读音命名义的问题。“乐读 yuè”“予读 yú”“微读 wéi”“知读 zhì”等情况保留各自原字典释义；不再套用不适用的项目字符意象、组合寓意、自然词表或语义加分。

新方案独立记录命名规则 4.0、生成字库和固定来源。旧方案继续保留生成时解释与评分，界面、导出确认和 PDF 明示未按新规则重算。3.0 原件、40 条／44 名出处、原字库和既有术数方法保持其原版本。

本轮继续原典逐条研究，没有新增完整判格方法。有效根气、同一载体的制化与救应、净旺衰、真假从、完整调候与合化，仍缺闭合条件；不以元素数量或开源作者权重代替。

说明见 [读音适用规则](NAMING-READING-RULES.md)。本文件说明变更范围；测试、生产构建、安装、SQL 与 PDF 的实际结果只以安装包旁验证记录为准。真实 AI、原生关闭新版复验、发布者签名及后续第二台 Windows 验收仍需单独完成。

字库及候选详情把原字库备注折叠保存，并标明可能未随所选读音调整；展开可查原文，方案的当前读写提醒单独显示。此显示调整另有3项新增界面测试及实际可见文字验收。
