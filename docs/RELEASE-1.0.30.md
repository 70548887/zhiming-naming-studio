# 1.0.30 离线原典全文检索与阅读

文化知识库新增“原典全文”：内置固定电子版本《滴天髓闡微》和《穷通宝鉴》，两书180447个原始码点、123节完整覆盖。支持逐字检索、书目筛选、分页目录、章节连续阅读、命中定位，以及“阅读／原始文本”切换。来源与许可随章节保留，穷通电子本9处私用字原样保留并提示核查。详见[全文库说明](CLASSICS-LIBRARY.md)。

本批另补7组作者原例、3份条件合同和42处原文范围，用于排除“相邻即通关”“见冲即损根”等不受原典支持的捷径。没有因此新增一个有效作用全部未知的传统方法，也没有启用缺乏完整前提的自动判格规则，见[作用原例研究](REN-ACTION-BRIDGE-RESEARCH.md)。

全文库与可替换知识包、客户档案和既有方案分开管理。新书源在当前来源页登记；旧方案、原典取法和姓名评分不回填新结论。浏览器预览与桌面使用同一全文服务；预览中省略书目筛选的JSON空值在服务边界归一处理，非法筛选仍拒绝。数据支持离线逐字节复现校验。

本文件记录实现范围，最终测试、实际安装、载荷、原始文本及报告验收结果以安装包旁的实际验证记录为准，不从专项测试推造完整发布通过。1.0.29及更早已交付安装包继续保留。

完整有效根气、净作用、调候、真假从、从儿／从旺／从强、合化和完整喜用仍待补齐；奇门姓名映射、真假空墓与四害解除，以及更广的语言和人口重名数据继续推进。真实AI联调、新版原生关闭两种选择、发布者签名和另一台干净Windows验收仍分别记录，跨机验收遵循用户此前的后续安排。
