# 1.0.9 审计修复：出生分析、审阅冲突与历史来源

本版处理 `AUDIT-1.0.8.md` 的 A01–A05。传统算法口径保持原版本；新增八字证据模块仍为未接线研究，不作为本版已启用功能。

## 已修复行为

- 当前八字规则快照按方案出生资料严格重建核验，包含四柱、五行、系统喜用、理由与警告；`originalFavorable` 必须与系统原始结果相同。人工五行选择仍独立保存。未知八字算法版本不擅自重算、拒绝导入；1.0.0至1.0.8使用同一受支持八字版本，旧方案无需补填字段。
- 正常出生资料和恢复路径复用同一民用时间解析。DST跳过的时刻拒绝，重复时刻维持取第一次并提示。11份完整分析的重构前后字节完全相同。
- 方案保存、收藏、数理确认、历史恢复和导出采用审阅修订号与随机令牌校验；过期客户端提交被拒绝，界面保留草稿并展示与最新内容的差异，打开最新版本前再次保护草稿。恢复备份重置当前方案令牌，避免同一数字修订号导致旧页面覆盖。数字修订号到达安全上限时拒绝修改，库仍可备份。
- 新生成方案保存不可变来源清单及数据版本；知识包后续更新不会替换。详情登记可在报告页展开，PDF内也包含来源地址、commit、哈希和许可。旧方案未保存清单时明确显示缺失，不能用当前库伪造历史。客户备份与审阅历史携带清单。
- Logo上传入口改为可聚焦原生文件输入，支持Tab、Enter和Space；保留原读取及草稿处理。比较按钮增加已选状态的无障碍表达。

38个测试文件、307项测试及TypeScript通过。隔离浏览器已验证双标签页冲突、草稿保护、15项来源登记，以及Tab/Enter/Space选图。当前Windows独立安装运行、开发工具PATH移除与系统密钥保护通过。37页PDF无空白或孤立短页，新增来源四页均已渲染目检；代码、样式、数据和文档与安装产物一致。具体记录见 `VERIFICATION.md` 及 `.local/fix-109/`。本版不将固定响应接口测试视为真实AI联调，不将当前Windows视为跨机验收。
