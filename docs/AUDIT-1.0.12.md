## 五、验证和验收缺口

- 本轮执行的是新的隔离复现、资料覆盖统计、交付物对比及依赖检查；未重复运行既有全套测试。上一轮 58 文件／462 项通过属于既有基线。
- AI 普通文本连通不等于结构化命名可用：本地 HTTP 夹具中，测试连接返回 200，生成添加 response_format 后返回 400。应区分“已连通”和“命名格式已验证”。这不是要求兼容所有模型；真实服务、真实密钥端到端验收未执行。
- 原生关闭提示的“继续编辑”和“放弃关闭”两种选择实操未完成；本轮未操作此前有人类输入的窗口。
- 另一台无开发环境 Windows 验收依用户决定留待后续，本轮不重新索要。
- 跨 Electron／ICU 时区库升级后的旧快照兼容尚需专项验收。本轮未复现跨库差异，不能称已有历史失效缺陷。
- 新一轮浏览器／屏幕阅读器全面联验未执行。此次 UI 新缺陷以源码事件复现和渲染证据为准。
