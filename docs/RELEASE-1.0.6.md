# 1.0.6 审计修复记录

本版面向 `AUDIT-1.0.5.md` 中的 A01–A05 和 B01/B02。后续界面与传统规则扩展继续按原规划推进。

## 设置草稿与分区保存

- 品牌与 AI 配置使用独立服务接口提交，只合并各自允许的字段。品牌操作不提交接口、模型、超时、AI 开关或密钥草稿；AI 操作不提交品牌草稿。
- 保存返回仅更新已提交部分的基线，请求期间继续输入的内容保留为未保存草稿。
- Logo 读取回调只合并图片字段；后一次图片选择优先于前一次迟到回调，并明确显示读取失败。

## 客户库与知识包

- 方案写入、历史归档和备份恢复执行完整的快照规范，拒绝重复候选 ID、非法审阅字段或不一致的内嵌对象。
- 生成客户与方案一次提交，提交失败回滚；延迟生成返回前若客户已被删除、编辑或恢复，拒绝覆盖更新后的档案。尚未首次保存的客户也受此保护。
- 知识包校验来源、引文、知识条目的 ID 唯一性及来源引用，包含读音义项中的来源；独立数理、奇门规则的来源编号为保留编号，不允许知识包占用。错误包不替换当前生效数据。
- 知识数据包只更新汉字、引文、知识与来源，数理与奇门规则仍随应用版本独立发布。
