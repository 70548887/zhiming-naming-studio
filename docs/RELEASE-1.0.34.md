# 1.0.34

文化知识库新增“历史姓名统计”，可浏览公安部2021年已登记新生儿男女各前十给名，并按明确给名查询公布名次与人数。统计范围、登记截止日期和官方来源随界面显示；未列榜的名字明确显示人数未公布，不生成0人、罕见或当前全国重名率结论。

数据在本地独立固定，知识包切换不替换它。查询不保存客户，不修改命名评分，不补写旧方案和报告。未将政府转载页的2025年生成元数据当成2025年度报告，也不将给名计数套用到包含姓氏的全名。具体口径见[历史统计说明](OFFICIAL-NAME-POPULARITY.md)。

最近的原生关闭人工实测在1.0.33完成：继续编辑保留未保存输入，放弃修改后原进程正常退出，隔离数据库不变，见[补充验收记录](../release/NamingStudio-1.0.33-native-close-verification.json)。本版验证范围与安装结果以本版包旁实际记录为准；不把1.0.33的人工实测写成另一场1.0.34原生按钮实测。

完整有效根气、真假从、合化及奇门姓名验局继续按原典条件推进，未闭合条件仍待核。完整全人口重名数据、真实AI服务联调、发布者签名和第二台干净Windows验收仍未完成；跨机验收沿用用户后续安排。
