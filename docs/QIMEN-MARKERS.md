# 奇门时旬空、时驿马：固定规则与来源

本轮只在既有时家转盘上补充两个辅助标记：**时旬空**和**时驿马**。它们标记固定地支方位，不随天盘、星盘、门盘、神盘旋转，不改变甲己符头拆补、阴阳遁、天禽随天芮及中五寄坤二的排盘规则，也不参与姓名排序。

辅助规则包版本：`hour-xunkong-yima/1.0.0`。单项规则为 `qimen-hour-xunkong/1.0.0`、`qimen-hour-yima/1.0.0`。每次结果保存规则版本、来源提交、适用条件及实际触发依据。历史版本不补造原来没有计算的标记。

## 1. 以时柱查时旬空

先确认有效的六十甲子时柱，再找所属十干支一旬，取该旬未被十天干配到的两支。

| 时柱所在旬 | 旬空两支 | 固定洛书宫 |
|---|---|---|
| 甲子旬 | 戌、亥 | 乾六 |
| 甲戌旬 | 申、酉 | 坤二、兑七 |
| 甲申旬 | 午、未 | 离九、坤二 |
| 甲午旬 | 辰、巳 | 巽四 |
| 甲辰旬 | 寅、卯 | 艮八、震三 |
| 甲寅旬 | 子、丑 | 坎一、艮八 |

两支同宫时保留两支，只合并宫号；例如甲子旬保留“戌、亥”，宫位只有乾六。仅据此不区分“全空/半空”、真假空、填实或冲空，也不套用截路空亡、孤虚、日旬空等其他规则。

## 2. 以时支查时驿马

本版本明确取**时支**，不取年支、日支或出生生肖，也不让AI自行切换取法。

| 输入时支所属三合组 | 时驿马支 | 固定洛书宫 |
|---|---|---|
| 申、子、辰 | 寅 | 艮八 |
| 寅、午、戌 | 申 | 坤二 |
| 亥、卯、未 | 巳 | 巽四 |
| 巳、酉、丑 | 亥 | 乾六 |

每个有效时柱必有一组旬空和一个时驿马。本版本的“未命中”指某个宫位没有该标记，并不表示整张有效盘可以没有旬空或驿马。两种标记可同时出现在同宫，不能互相覆盖，也不由此断吉凶。

## 3. 地支与固定方位

| 地支 | 固定宫位 |
|---|---|
| 子 | 坎一 |
| 丑、寅 | 艮八 |
| 卯 | 震三 |
| 辰、巳 | 巽四 |
| 午 | 离九 |
| 未、申 | 坤二 |
| 酉 | 兑七 |
| 戌、亥 | 乾六 |

中五没有地支方位，因此本取法不会产生“旬空落中五”或“马落中五”。中五的奇仪寄到坤二、天禽随天芮移动，都不把固定地支标记带走。测试覆盖旬首居中及天禽寄宫，但中心格仍没有这两个标记。这是本次两条规则的适用范围，不推论其他奇门标记也如此。

以上是两个开源实现的固定、可追溯约定，**不等于已取得两套独立、同师承原典的整盘背书**。本轮不重新证明整张奇门盘；原有同取法例盘保留，用于验证新增标记不会改变旧盘。对这些不参与盘层转动的辅助规则，独立期望直接取自外部固定表，不由待测应用生成。

## 5. 独立例盘与边界验证

`tests/fixtures/qimen-markers-examples.json` 包含：

- 60个外部六十甲子时柱例，覆盖六旬、十二支、四种马支，并分别配阳遁/阴遁局；每例保留命中宫位以及全部未命中宫位。
- 4个既有固定例盘：阳五庚申、阴三辛亥、旬首居中以及中宫奇仪随天芮寄宫。其辅助标记另从外部表得出，不抄应用输出。
- 12个单独转录的查表锚点，每旬两例，并交叉核对两份旬空表及“每旬缺少两支”的定义。
- 8个民用时间边界例：2024年夏至前后、立春前后、22:59:59、23:00:00、23:59:59及次日00:00:00。

每条规则至少有3个命中宫和3个未命中宫的独立例盘；全部64个干支例均检查中五无标记。六旬每旬至少10例，四种马每种至少15例。固定宫位的顺序以宫号升序存储，不以旬空两支的书写顺序推断。

民用边界例的日、时柱用独立公历整数日算法和五鼠遁运算，锚点为公历2000-01-07甲子，未导入应用领域函数或 `lunar-typescript`；这只独立核对日时干支与新增标记。节气前后时间沿用既有已核验日历锚点，本轮没有新增独立天文交节算法。应用现有规则按民用午夜换日，23点进入子时但日柱保留当日；夹具按这项明确约定计算，不能拿另一日界流派的23点换日结果作反例。

验证命令：

```powershell
node scripts/verify-qimen-marker-evidence.mjs
```

该脚本读取固定外部表、独立手录锚点、来源锁及夹具，不导入 `src` 或应用历法库。它校核六旬互补、两源一致、地支取宫、取马、期望及反例，不以生产实现替自己生成答案。`--archive --write` 只供开发者在重新审核固定版本证据后重建归档与夹具，发布验证时使用不带参数的只读命令。

## 6. 暂不启用的结论

1.0.8已按独立规则包加入门迫、天盘宽式击刑、所选三奇入墓和星门结构原位/对宫；范围与来源见 `QIMEN-STRUCTURAL-PATTERNS.md`。它们不由旬空/驿马自动推出。姓名落宫仍没有可核验的固定取法，本版本不把笔画、拼音或字序自行映射到宫位，也不声称新增标记可以“验名通过”、改变命运或替代八字喜用神判断。时刻未知或时柱无效时不补造唯一旬空/驿马。
