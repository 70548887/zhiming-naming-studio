## 开发与构建

需要 Node.js 22.12+、24.x 或26+（与测试工具兼容的版本）（发布版不需要用户安装 Node）。

```powershell
npm ci
npm run data:build
npm run data:numerology
npm run test
npm run build
npm run desktop
npm run package
```

以下是仓库常规开发命令，不是当前组合已通过的运行记录。当前 source-prebuild 仍有未获准入项，正式 Electron 构建与打包须待精确来源门禁通过；本轮只检查文档，没有运行这些命令。

首次 `data:build` 使用固定提交与快照来源，下载到 `data/raw` 并核验；已存在且哈希匹配的只读文件可离线复用。安装包仅带加工后的数据库、源记录和必要许可，完整原始快照保存在开发目录以便复现。

桌面版采用单实例锁，重复启动聚焦已有窗口。客户库写入还有互斥与磁盘版本核对；遇到其他进程修改时取消陈旧写入并提示重新打开，不会覆盖其他进程的新记录。备份恢复先核验完整性、主键和嵌套字段，再导入标准结构并原子替换；失败时保留当前库。

同一资料再次生成会排除此前已展示名字，合格候选用尽或不足时明确提示。不同客户的偏好各自保存；慢速AI返回的旧请求只更新原客户历史，不覆盖当前新输入。

`npm run dev` 启动浏览器开发预览。预览使用真实本地计算和单独的 `.local/preview` 客户库；系统文件选择器、PDF、备份等操作需在桌面版使用。预览密钥仅在服务内存保存，桌面版才使用 Windows 加密存储。

客户资料默认保存在 Electron 的用户数据目录 `%APPDATA%/zhouyi-naming-studio`。可通过环境变量 `NAMING_STUDIO_USER_DATA` 指向独立目录。恢复前备份为该目录下 `customers.before-restore.sqlite`；知识库回退副本为 `knowledge.previous.sqlite`。API 密钥不进入客户备份，在其他 Windows 账户恢复后需要重新配置。

客户备份另保留生成时完整知识包归档，按完整SHA-256和版本映射核对字音、字典记录、引文与来源；后续更换数据包不覆盖旧方案。内置版本核对与自定义包内容一致分别标示，自定义归档不等于上游真实性认证。缺少原包的旧外部方案明确保留未核验状态；新方案的已核验记录不通过删除原包降级。归档上限为100包或150MB，到达上限会拒绝新增操作并保留历史。
